Every value here is rendered from what the view returned; the template computes nothing and assumes nothing. `cell.bucket` is the classification `attendance.period` produced — the same one the monthly table counts with — so this file only decides how each bucket is drawn. `rows` is the current page's grid; `page` is the paginator for it; `totals` describes the whole filtered set, and `totals.lists` holds the employees behind each card, in card order. The card counts are always the true totals; only the rendered names are capped, with the remainder stated. The modal lives here, next to the cards it belongs to, so an HTMX swap replaces both together and they can never disagree. Its open/close handlers are delegated from `document` in the shell, which HTMX does not swap. {% endcomment %}
